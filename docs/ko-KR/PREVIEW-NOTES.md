# 한국어 미리보기 주의 사항

이 산출물은 코드 서명되지 않은 비공식 팬 빌드이며 PoE1 한국어 기능만 대상으로 합니다. 현재 저장소에는 로컬의 안전한 픽스처 검증 결과만 기록되어 있습니다. 별도 승인을 받아 GitHub의 hosted Windows 빌드를 수동 실행하기 전에는 네이티브 빌드, 실행 파일 자체 점검, ZIP 해시 검증이 성공했다고 간주하지 않습니다.

첫 공개 미리보기 전에 다음 화면과 동작을 사람이 직접 점검해야 합니다.

- 실행기
- 설정
- 필터 편집기
- 아틀라스 플래너
- 패시브 관련 도구
- 아이템 붙여넣기
- 오류 대화상자

이 수동 점검이 끝나기 전에는 Release를 만들지 않습니다. 소스가 공개되어 있다는 사실은 빌드 파일의 신뢰성을 대신하지 않으므로, 설치 안내에 따라 게시된 SHA-256을 별도로 비교해야 합니다.
