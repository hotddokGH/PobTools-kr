# PobTools 한국어 미리보기 설치

PobTools 한국어 미리보기는 **Path of Building Community를 포함하지 않습니다.** Path of Building Community는 별도로 설치하고, 압축을 푼 두 폴더를 다음처럼 같은 상위 폴더 아래에 둡니다.

```text
도구/
├─ Path of Building Community/
└─ PobTools-Korean-preview/
   ├─ pob-zh.exe
   ├─ pob-zh.ini
   └─ Data/
```

`pob-zh.ini`에는 `Game=poe1`과 `Locale=ko-KR`이 설정되어 있어야 합니다. 이 미리보기의 `pob-zh.exe`는 코드 서명되지 않은 비공식 팬 빌드입니다.

실행하기 전에 배포 페이지에 표시된 ZIP의 SHA-256과 다운로드한 파일의 SHA-256을 비교하십시오. 해시가 다르면 실행하지 말고 파일을 삭제하십시오. 해시가 같고 출처를 직접 확인한 경우에만 Windows SmartScreen의 **추가 정보**를 선택한 뒤 파일 이름과 게시 정보를 다시 확인하고 **실행**을 선택할 수 있습니다. 오픈 소스라는 사실만으로 파일이 안전하거나 신뢰된다는 뜻은 아닙니다.
